# Tech B.Log

김상훈의 개인 개발 블로그 — 만들고, 부딪히고, 배운 것을 기록합니다.

**블로그:** https://noahwannagohome.github.io/tech-b-log/

백엔드 개발, 개발 환경과 자동화, 인프라, AI 등 개발하며 쌓은 경험과 문제 해결 과정을 담습니다. 특정 프로젝트 전용 저장소가 아닙니다.

## 구성

- `index.html`: 글 목록과 블로그 소개
- `about.html`: 작성자와 기록의 방향
- `articles/`: 개별 글
- `assets/`: 스타일과 아이콘

## 글 추가

1. `articles/`에 새 HTML 글을 추가합니다. 기존 글의 공통 헤더와 푸터를 활용할 수 있습니다.
2. `index.html`의 글 목록에 날짜, 제목, 태그, 요약과 링크를 추가합니다.
3. 글 개수를 갱신하고 `main` 브랜치에 반영합니다.

별도 설치나 빌드 없이 GitHub Pages가 `main` 브랜치 루트의 파일을 게시합니다. 실제 서비스 소스코드는 별도 저장소에서 관리합니다.
